森林照片环绕

9 秒 · 1280 × 720 · 30 fps · 无音轨

怎么玩

播放或慢放，拖动时间轴观察照片如何绕过人物。开关四个图层，可以看清前后遮挡。选择自己的照片后，它们会循环填充 12 个卡片位置。

照片替换仅保留在当前预览，刷新后恢复默认。网页不会自动上传所选照片。下载视频是默认森林照片的成片。

复刻范围

参考「录屏2026-10-08 12.16.51.mov」中约 3 秒之后的有效运动段，重建照片环绕、透视、前后穿插、轻微浮动和标签进入。

森林与透明人物参考原片关键帧生成重建，照片为生成的森林摄影图集。人物使用静态前景层，不包含原片口型和手势变化。

继续编辑

工程使用本地 HTML、CSS、JavaScript 和素材文件。assets/orbit.js 控制环绕运动，assets/orbit.css 控制卡片与场景样式。交互预览与视频渲染共用运动代码。

需要将自己的照片渲染为新成片时，将图片放到 assets/，在合成初始化后调用 orbit.replacePhotos(['assets/your-photo.jpg']);，打开 HyperFrames Studio 后检查和渲染。

npm run studio
npm run check
npm run render

项目固定使用 HyperFrames 0.8.139。渲染需 Node.js、Chromium 浏览器与 FFmpeg。完整代码和素材可从 GitHub 镜头库获取。
