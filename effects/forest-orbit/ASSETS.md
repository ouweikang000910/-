# 素材与动效来源

参考：用户提供的「录屏2026-10-08 12.16.51.mov」，分析帧约为源视频 4.3 秒。参考中的软件界面、字幕及录屏本身不作为公开镜头内容。

| 文件 | 来源与用途 |
|---|---|
| assets/forest.png | 依据参考帧，经 imagegen 移除人物、悬浮照片及软件文字，补全森林背景。 |
| assets/person.png | 依据参考帧，经 imagegen 重建并提取透明人物前景。为静态前景图，保留灰色上衣、背包肩带、手机和坐姿。 |
| assets/photos.png | 经 imagegen 生成的 4×3 自然摄影图集，共十二张不同的森林、叶片、溪流等照片。 |
| assets/gsap.min.js | 本地 GSAP 运行时，原项目已有。 |
| compositions/components/three-orbiting-cards.html | 已安装的 HyperFrames 注册表组件，提供可寻址的 paused GSAP 代理状态与纯渲染适配方式。原组件不进入最终渲染，实际几何改为 CSS3D 照片轨道。 |

动效实现以固定的世界坐标、角速度、相位和浮动频率计算每一帧，没有时钟、随机数或渲染期网络请求。透视由浏览器的 CSS3D 深度空间实现，人物图层位于 z=0，背后照片位于负 z，前方照片位于正 z。

素材的生成提示词和文件溯源记录于「生成记录.txt」。
