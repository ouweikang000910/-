# 森林照片环绕

workflow: motion-graphics
flow: autonomous

用户提供「录屏2026-10-08 12.16.51.mov」，要求复刻其中动效，保存到桌面「视频动效库」，同时上传现有 GitHub 镜头库。录屏开头约三秒为停帧；本项目复刻后面的有效运动，输出 9 秒、1280×720、30fps、无音频的独立镜头，并提供本地可替换图片、分层查看、任意时间拖动的互动网页。

核心运动是十二张白边自然照片围绕坐在森林中的人物做椭圆投影的 3D 环绕。近景卡片变大、下移并遮住躯干；远景卡片变小、上移并被透明人物前景遮挡。每张照片随圆周位置转向，侧面窄、正面宽，叠加轻微浮动。人物和森林固定。5.6 秒出现小白色「the-meta colorize」标签。移除录屏的软件界面、评论和字幕。

复用注册表组件 three-orbiting-cards 的 paused GSAP 状态与纯时间渲染适配模式。用 CSS3D 代替其 WebGL 立方体表现：本地文件即可打开，支持真实前后遮挡，无远程依赖。共用 assets/orbit.js 和 assets/orbit.css，互动网页与 HyperFrames 导出保持相同投影与节奏。

使用根据参考帧生成的森林补全、人物透明前景与十二张自然照片图集。复刻的是动效结构和视觉关系；人物前景为静态重建图，不复现录屏人物的口型或手势。来源和生成方法记录于 ASSETS.md。

保存、渲染和上传均已获用户本次请求授权。验证后由主代理完成 MP4 导出、桌面入库及现有镜头库发布。
