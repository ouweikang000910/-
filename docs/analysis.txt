视频动效库 / 001：人物竖卡转场
来源：录屏2026-10-07 17.12.35.mov
录屏时长：7.7767 秒；2940 × 1912；可变帧率，平均约 43.97 fps；没有音轨。
时间基准：录屏起点为 0 秒，不是抖音播放器显示的时间。分段时间约 ±0.05 秒。

核心结构
室内原场景 → 科技竖卡从人物身后升起 → 人物缩小落入卡片 → 卡外原背景淡出 → 顶部标签出现 → 右侧关键词展开。
它不是把完整原视频直接缩小进卡片。复用时应将人物、原背景、科技卡片、发光边框、标签和关键词分层。

01. 竖卡从下方升起 / 约 2.65–3.16 秒
观察：圆角科技背景先在人物身后出现，从画面底部上升，宽度基本保持稳定，最后停在中央。人物始终位于它前面。
复现：Y +520 → 0 px；透明度 0 → 1；约 0.51 s；power3.out。卡片宽 46%、高 92%，圆角约 5%。

02. 人物缩小，落入卡内 / 约 3.12–3.55 秒
观察：人物从原场景中的大半身画面，缩小到竖卡内部；科技背景替换人物身后的室内背景。人物边缘存在柔和的浅色轮廓。
复现：人物 scale 1 → 0.82；Y 0 → 76 px；约 0.43 s；power2.inOut。实际复用需先抠像或有透明人物素材。

03. 原背景淡出，辉光留住主体 / 约 3.18–3.75 秒
观察：竖卡基本到位后，卡外原场景逐渐变暗并被深色背景接替。卡片边缘出现蓝白色的柔光，将主体从暗场中分离。
复现：室内背景 opacity 1 → 0，约 0.57 s；辉光约 24–42 px，亮度与背景接替同步。不是整幅画面一起压暗。

04. 顶部标签由小到大出现 / 约 3.43–3.68 秒
观察：灰色半透明底板与绿色“商用AI”一起放大出现，停在卡片顶部。文字与底板作为一组运动，不是逐字打字。
复现：scale 0.1 → 1，opacity 0 → 1；约 0.25 s；power3.out。原片未观察到明显大幅回弹。

05. 右侧关键词纵向展开 / 约 5.88–6.04 秒
观察：“价格昂贵”先表现为很薄的一条横向文字，再迅速恢复正常高度，位置在人物右侧，并部分跨过卡片边缘。
复现：scaleY 0.03 → 1；opacity 0 → 1；约 0.16 s；power2.out。无需额外横向飞入。

06. 科技纹理与稀疏粒子 / 约 3.25–7.77 秒
观察：竖卡内有斜向蓝色科技纹理，卡外深色场景有零散金色亮点。它们提供空间感，运动幅度低于人物与标签。
示意复现：固定种子粒子，小幅上漂与透明度变化；蓝色网格缓慢位移。原片具体素材、插件与噪声算法不可从录屏确定。

字幕：白色粗体、黑色描边/阴影、下方居中。本段为整句替换，没有明确的打字动效。
不计入动效：人物讲话和手势、鼠标、抖音按钮、桌面 Dock、录屏结束工具条。

制作参考
剪映/PR：复制人物素材，主体层智能抠像；原背景单独保留；科技背景加圆角蒙版和位置关键帧；人物加缩放/位置关键帧；底层原景透明度淡出；标签缩放入场；关键词用纵向缩放/蒙版展开。
AE：人物 Roto Brush 或带透明素材；科技背景预合成加圆角遮罩；主体独立变换；辉光放在卡片背后；标签与底板预合成共同缩放。
代码：离线 HTML 使用 GSAP 可寻址时间轴。完整可编辑项目见 render-project，无需在线素材即可预览可视化 HTML。

说明
本库复现的是运动机制与先后关系。人物使用插画示意，蓝色网格是自制近似素材；真实画面和原片对照保存在本地动效库，不随代码仓库上传。
参数、颜色、缓动曲线是供复用的建议，不能视作原视频作者工程的精确数值。
可编辑合成画布为 1280 × 720，时长约 7.78 秒。仓库不包含原始录屏或导出成片。

使用方式
双击根目录 index.html；点击播放或重播；拖动时间轴；选择 0.25×/0.5×慢放；点击右侧动效条目定位；“只播放这一段”查看局部；分层开关查看合成关系。
